# 塔升级外观设计（风车帆布风格）

模型脚本：`build_windmill_towers.py`（同一文件夹）。导出：`export_towers.py`。预览图：`previews/upgrades_cannon.png`、`upgrades_catapult.png`、`upgrades_sniper.png`。
Blender 里的 "TowerUpgrades" 场景每座塔一排，从左到右：基础 → 路线一 → 两个分支 → 路线二 → 两个分支 → 满 3 星。

## 玩家靠三层信息区分升级

1. **颜色说明作用**：塔上所有帆布条纹、旗帜、风车帆、炮身色环都换成该升级的颜色。同一种作用在三座塔上用同一种颜色，玩家学一次就能通用。
2. **条纹图案说明路线**：基础是横条纹；路线一改为竖条纹（像遮阳篷）；路线二改为下摆染色（帆布下半截整块上色，上面再加一道色带）。
3. **塔身大件说明分支**：每个二阶分支都在塔身上加一个远看就能认出的大部件，例如烟囱、石墙、窑炉、第二个风车、木板护甲。

## 接入游戏的约定（已接入）

游戏端：`sakura_valley/scripts/tower_models.gd`、`shaders/tower_cloth.gdshader`、`data/tower_models.json`。
导出（在仓库根目录）：`E:/blender/blender.exe --background --factory-startup --python art/models/towers/export_towers.py`，加 `-- --renders` 重画预览图。

- `export_glb()` 每座塔导出一个 glb 到 `sakura_valley/assets/models/towers/`，所有升级部件都包含在内。同一节点下、显示条件相同的零件合成一个网格（每座塔约 28 个）。
- 升级部件带两个自定义属性，glTF 会导出为节点的 extras：
  - `wt_requires = "a,b"`：升级路径包含这些全部 id 时才显示。
  - `wt_unless = "c,d"`：路径包含其中任一 id 时隐藏（即被替换掉的部件）。
- 星级的 id 为 `star1` / `star2` / `star3`。
- 每种武器形态有自己的炮口节点：`<塔>_Muzzle` 和 `<塔>_Muzzle_<升级id>`。风车转子节点名以 `_Vanes` 开头。游戏会转动所有可见的转子。
- 颜色和图案：
  - 凡是用到 `WT_sky` 材质的面，都属于"强调色"槽位。
  - 帆布网格带有 UV（u 为横向，v 为纵向），游戏里的帆布着色器可以根据 v 或 u 画出三种条纹。
  - 颜色表和图案表在 `sakura_valley/data/tower_models.json`。脚本里的 `ACCENTS`、`UPGRADE_ACCENT`、`LINE_PATTERN` 只用来画 Blender 预览，改颜色时两边一起改。
- 游戏只认 `<塔>_Yaw` 和 `<塔>_Pitch` 两个节点转动炮口，`_Muzzle` 节点暂时没用到。
